# Net Positioning — Estimated

**Net Longs — Estimated** and **Net Shorts — Estimated** are separate native lower panes. Each pane keeps its own method and selected perpetual venues; settings are saved with the chart. Available sources are Binance BTCUSDT USD-M perpetual and Hyperliquid BTC perpetual. The staging worker reads the recorder API and shares its bounded history and polling work across both panes. Fixture mode and direct venue connections never stand in for recorder data.

Choose **Price + OI** or **Aggressor Flow + OI**. For an observed source interval, the estimator compares the BTC-sized open-interest change between adjacent observations with either the same-feed price direction at the interval boundaries or the same-feed aggressor buy-minus-sell flow. It assigns that signed change to the matching side; neutral direction is shown as unclassified. The application aggregates the recorder's exact decimal quantities into the host candle whose `[open, close)` range contains the source interval's effective end time. An end timestamp exactly on a candle boundary belongs to the candle opening at that boundary.

Source observations arrive at 30-second resolution. **Stacked** is the default: each source keeps its original signed BTC contribution, positive values accumulate above zero and negative values below zero. Positive and negative totals remain independent; values are never split between signs or converted to absolute amounts. **Grouped** keeps each source's individual value, including a source's selected slot when it has no observation for that candle. Colors identify the venue in either pane and on both sides of zero: Binance is muted amber (`#c39b58` dark / `#946820` light), Hyperliquid is muted blue (`#719aca` dark / `#3e71a6` light). Segment labels use whichever near-black or near-white foreground has higher contrast against the source fill. Valid saved source-color overrides remain in effect. Both modes calculate scale extents from the visible candle range. Changing display or label settings does not change the worker request or remount the panes. Shared cumulative boundaries round to device pixels to avoid seams.

Only observed source intervals are drawn. A true observed zero is marked at the zero line; a missing or unavailable interval leaves no bar. Partial source coverage uses reduced opacity and remains identified as partial in the tooltip. The panes do not fill gaps or interpolate. The recorder request spans at most four hours, and each method retains at most 2,000 intervals in the worker and shared candle history. The compact source legend has keyboard-focusable buttons that emphasize that source's visible segments. **Auto** value labels appear only when measured text fits within a segment; **Hover only** waits for a segment hover; **Off** hides labels. A tooltip reports the available and unavailable interval counts, source resolution and latest interval start/end, feed freshness, BTC unit verification, both side estimates, OI change, unclassified quantity, the signed hovered contribution, and the selected method's price or trade inputs. The current host candle remains provisional until the candle closes.

This is an estimate of long-side or short-side activity. Open interest is one side of matched positions and these inputs cannot distinguish whether activity opened or closed risk. Price-based classification also depends on fresh price observations at both boundaries; flow-based classification requires complete trade coverage across the same interval. Hyperliquid OI timestamps are collector-sampled, as indicated in the tooltip. Collection and history depend on the staging recorder's availability and start time.
