# Native chart drawings

## Create and edit drawings

On Binance BTCUSDT Spot, Binance BTCUSDT USD-M Perpetual, and Hyperliquid BTC Perpetual candle charts, choose from the left drawing sidebar: **Lines** contains trend line, horizontal line, horizontal ray, Arrow, Projected path and Brush; **Shapes and Fibonacci** contains rectangle and Fibonacci retracement; **Position tools** contains long and short position; **Text Tools** contains Text and Callout. The cursor/select control sits above these groups. Group icons use the last selected tool, and their chevrons open the related tools. Horizontal lines, rays, and Text finish with one anchor; trend lines, rectangles, Fibonacci retracements, position boxes, and Callout bubbles finish with two. Callout's first anchor marks the tail and its second anchor places the bubble; its default content is **Note**.

The anchor icon cycles **Off → Weak → Strong → Off** snapping to candle values; holding Ctrl/⌘ temporarily enables strong snapping. The active tool or erase mode has a pressed state in the sidebar and is announced to assistive technology. Click the chart to place anchors. Rectangles also support press–drag–release placement: a temporary outline follows the pointer while held, then the native controller commits one drawing and one undo step on release. A preview is temporary; the drawing is saved and enters native Undo/Redo history when placement completes. Undo, Redo, Erase, Style and Templates stay in the left sidebar. Object Tree is toggled from the matching right sidebar. Arrow uses two anchors; Projected path accepts clicked vertices and finishes on double-click; Brush finishes on release and retains at most 512 native time/price anchors after simplification. Escape cancels a preview.

Select a drawing and use **Style** in the sidebar or its Object Tree row to edit the native controls available for that tool, its interval range, and IQTerminal metadata. Rectangle controls include border width/color, fill color/opacity and optional right extension; Fibonacci controls include editable levels and label visibility. A custom label is drawn at the anchor of horizontal lines and rays using the drawing's text style. Their numeric price tags appear in the native price scale in the drawing's stroke color, not beside the ray's start point. The custom annotation stays at its anchor, follows the stroke color until a user explicitly chooses **Text color**, and templates preserve that choice; Text and Callout render their native `Drawing.text.value` once. The analysis interval is a separate annotation from visibility: a drawing tagged **4h** can remain visible on a 1m chart. Its **From** and **To** interval range controls where it appears, and **Hide/Show** is an independent visibility switch. Applying a template or changing an analysis interval does not switch the chart timeframe.

## Object Tree

Each candle chart has its own right-side **Object Tree** sidebar, hidden on new charts and 280px wide when opened. Saved visibility is preserved. Drag its left edge to resize it between 200px and 520px, or hide it completely and reopen it from the right sidebar's **Object Tree** control. Resizing changes the chart's available width without rebuilding its engine or reloading its feed.

The tree can hold folders, drawings and supported indicator instances at any level up to eight folder levels. Create folders and subfolders, rename them inline with **F2**, reorder or move items by dragging, or use each row's actions menu to move items to a folder. Delete a folder while keeping its contents, or remove its descendants through their drawing actions. Arrow keys navigate the visible rows; **Enter** selects a drawing or expands a folder, **Space** changes drawing visibility, and **Alt+Arrow Up/Down** reorders the focused item. Drawing context actions retain the native select, visibility, lock, settings, duplicate, reorder, and delete operations.

Each folder's eye reflects all, none, or mixed visibility among its descendant drawings. **Show all drawings** explicitly sets every descendant visible, including drawings previously hidden on their own; **Hide all drawings** explicitly hides them. The operation is one native Undo step and only changes visibility, preserving each drawing's interval range and analysis interval. Folder membership is display metadata: drawings keep their native IDs and behavior.

Folder creation, rename, move, reorder, and removal are Object Tree metadata changes and do not add entries to the chart's native Undo history. Undo applies to native drawing edits, including a folder's bulk visibility command.

Supported indicator instances can be organized alongside drawings in folders. The remaining **Other chart objects** inventory holds unowned native sources/objects with only their supported actions. Folder eye controls apply to descendants; native drawing history and indicator settings retain their existing ownership. Folder **Show in sidebar** pins a visibility toggle under the Object Tree button; choose a drawing icon, A–Z or 0–9, and hover/focus for the folder name.

The Object Tree sidebar belongs to its candle chart and groups non-drawing rows under the main pane or their actual chart pane. Rows within each pane retain the native object inventory order. The primary source row cannot be removed. Drawing rows provide compact tooltip-labelled **Hide/Show**, **Lock/Unlock**, **Duplicate**, **Style**, and remove icons. Right-click a drawing for Delete, Clone and Settings; outside click or Escape dismisses the menu. The inventory also exposes Footprint, Order-book Heatmap, Order Walls, Trade Bubbles, Level Watch zones, and script-backed studies when those providers are active. Provider rows offer only their supported actions; Trade Bubbles exposes visibility, settings, and removal while collection continues when hidden. Script studies expose visibility, settings, and removal, with no lock action. Undo and Redo buttons work with **Ctrl/⌘+Z** and **Ctrl/⌘+Shift+Z**; **Ctrl/⌘+D** duplicates the selected drawing. Drawing tool hotkeys are shown by their native toolbar controls when available.

## Templates

Open **Templates** with a drawing selected to save its settings under a name. Records are scoped to a tool; saving the same name for that tool updates the record. **Include label** is independent of the label field: leave it off to preserve the target drawing's current annotation when applying, or turn it on to copy the text. An included empty label explicitly clears the target label.

Applying a template changes the selected drawing's settings in one undo step while keeping its anchors and identity. It copies settings into that drawing; later edits or deletion of the catalog record do not change drawings that were already applied. **Set default** uses the template for later placements of that tool. Favorites stay at the top of the template list.

The Templates panel offers opt-in everyday presets: Yellow outlined zone, Blue shaded zone, Weekly level, Pulled-wall note and Red scenario path. Installing them does not overwrite existing names or defaults. Arrow/path/brush use the same controller, history, snapping, favourites, floating toolbar, templates and persistence as existing tools.

## Chart journal

Use the chart-header capture action, chart context menu or **Alt+Shift+J** to save a PNG and immutable settings immediately. Shift-click captures then opens optional reasoning. Timestamped Journal indicator markers reopen entries across timeframes for the exact market. **Open saved chart** restores settings in a fresh chart; it does not replay historical data. See [Journal Release 1](journal-release1.md) for capture semantics, backups, limits and the daily walkthrough.

## Saved data

Each chart panel stores a separate drawing document for each instrument in browser `localStorage`, under `iqterminal:drawings:<encoded panel id>:<encoded venue:market>:<encoded symbol>`. The chart interval is outside the key, so changing timeframe keeps the same instrument's drawings. Spot, USD-M perpetual, and Hyperliquid perpetual have distinct scopes. Chart layout restoration retains panel IDs; closing a chart disposes its live controller but does not delete the saved document for that panel and instrument. A newly created chart has its own panel scope.

Object Tree folders and optional drawing display names use versioned records at `iqterminal:object-tree:v1:<encoded panel id>:<encoded venue:market>:<encoded symbol>`, with no timeframe in the key. Sidebar width and collapsed state use the sibling panel-scoped record `iqterminal:object-tree-sidebar:v1:<encoded panel id>`. Invalid or unsupported records are preserved and the affected tree uses session memory with a visible status message; failed writes do not disable chart drawings.

Templates use the separate versioned catalog `iqterminal:drawing-templates:v1`. Malformed or unsupported stored drawing/template data is left untouched; the affected feature uses an in-memory session copy and reports the storage issue. If a drawing-document write fails, drawings remain usable in the current session but edits made after the failure are not guaranteed to survive a reload.

## Verification limits

`tests/browser/object-tree.spec.ts` uses the explicitly selected fixture mode to cover sidebar resizing/collapse, panel/feed continuity, folders, nested drag-and-drop, bulk visibility history, per-instrument persistence, and corrupt storage. `tests/browser/drawing-tools.spec.ts` covers each tool's anchor count, Callout text placement/editing/templates/history/reload, settings and template history, Object Tree actions and active-panel ownership, instrument/panel storage, write failures and corrupt data, Footprint/Heatmap overlays, and Level Watch visibility and picker disarming. `tests/object-tree.test.ts` covers the versioned catalog, storage, reconciliation, moves, ordering, and folder operations; `tests/drawing-templates.test.ts` covers template catalog parsing and repository behavior. Fixture browser checks do not certify live Binance or Hyperliquid connectivity or platform frame-rate performance.
