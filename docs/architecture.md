# T0 boundaries

`main.ts`, `layout.ts`, `panel.ts`: native DOM shell, typed candle panel registry, create/update/dispose, versioned validated Dockview JSON with debounced storage. Bad/unknown/oversized layouts fall back to the initial pair. Zero panels is a persisted valid empty state. Storage contains configuration/layout only. Eight panels/WebGL contexts maximum. Dockview handles free docking, tab grouping, reordering and splitters; floating/popout features are disabled or unexposed.

`feed/worker.ts` runs one dedicated worker per browser tab. `service.ts` owns one socket per active venue, ref-counts exact venue/native-symbol/interval series and de-duplicates in-flight history. Unused series are immediately evicted (zero inactive cache). At most eight active series, 5,000 bars each, 512 pending distinct timestamps per series; overflow sends a new snapshot. Pending patches flush at 20 batches/second. Structured cloning small patch messages preserves ownership; no canonical buffers are transferred. Initial history is about 1,000 bars. Cache/model pruning leaves a 128-bar slack after rollover, preserving the viewport's timestamp anchor.

Adapters validate identity, finite OHLC relationships, cumulative BTC volume, UTC millisecond open time. Reconciliation uses timestamp keys: history revision=0; Binance live revision=exchange event time; Hyperliquid live revision=trade count because candle messages lack a separate event sequence. Higher revision wins, equal revision uses last receipt unless it would reopen a closed candle. Equal-count Hyperliquid updates therefore have an explicit receipt-order tie-break; authoritative ordering cannot be inferred beyond the provided fields. Live can arrive during history; history cannot replace a live revision. Volume is replaced, never summed. Initial/repair snapshots are sorted and idempotent. Client subscription tokens and worker request generations reject obsolete selections/responses, including switch-away-and-back races.

Reconnect resubscribes and fetches recent overlap/gap with the same merge rules, retaining existing history. Repair is limited to the latest 1,000 intervals, matching T0's bounded recent-history scope; no infinite backfill. History timeout 15s, bounded backoff 1–30s with jitter, five automatic transient retries; hard HTTP rejections require Retry. Browser WebSocket errors hide handshake HTTP details, so repeated unsuccessful connects also stop after five. Binance uses protocol heartbeat handled by the browser and proactively rotates before the documented 24h lifetime; no application ping. Hyperliquid sends its documented ping every 25s and checks message freshness. Socket-open does not imply live: valid candles drive last-update time, 15s silence becomes stale. Offline/online and independent venue failure are handled.

`chart/model.ts`: DOM/wire-independent Float64 structure-of-arrays store; bar-index spacing, real UTC timestamps, linear prices, bidirectional transforms, visible-range autoscale, minimum 3px spacing and maximum 40px. Missing intervals are compressed, with real timestamps on labels/lookups. Flat/empty price domains get finite padding. Pan/zoom stay intact during docking, tab activation and repair; only Latest/following moves to the end.

`chart/renderer.ts`: first-party GLSL, one instanced draw of two rectangles per visible candle plus a small margin, scissored to the plot. CPU double prices become CSS pixel geometry before Float32 upload, avoiding absolute-price/epoch precision loss. GPU buffers persist; changed visible ranges update with bufferSubData, while scale/structural changes regenerate visible geometry. Crosshair-only invalidation redraws the sparse Canvas overlay without rebuilding/uploading candles. Font/number/date formatters are reused. Backing DPR is capped at 2 to bound fill cost; coordinates remain CSS pixels. One context per panel, released on close; loss/restoration and unavailable WebGL keep layout and shell usable. No readback or GPU timing claims.

`chart/controller.ts` handles DOM input; one application RAF scheduler paints dirty visible charts and stops idle/hidden. Hidden tabs retain bounded data without paint/uploads or readout changes and catch up on activation. ResizeObserver ignores zero sizes; routine docking/resize preserves chart instances. HMR/page disposal terminates worker, timers, observers and inputs.

## Later milestones, not implemented

The small render-layer contract receives shared viewport/transforms and invalidation. Footprints need separate trade ingestion, per-price bid/ask aggregation, retention and dense text; OHLCV cannot reconstruct them. Candle service protocol can gain separately typed streams without leaking exchange formats into chart code.

Numeric indicators should consume bounded snapshots/deltas and return host-rendered outputs. A bar-open timestamp identifies a revision to the forming observation; a transition to closed/new timestamp identifies a new closed observation. Indicator scheduling must distinguish these rather than count every forming update. Calculation stays outside rendering.

User scripts require a separately designed restricted runtime, budgets and cancellation. A Worker alone is not a security sandbox; T0 has no eval/new Function, script editor, interpreter or language choice. Future script execution must not share the feed loop.

Rust/WASM may help measured bulk aggregation, backfills or numeric kernels using batched calls across the existing DOM-free boundary. Host rendering remains owned here. OffscreenCanvas/WebGPU are later benchmark questions, not assumed speedups. AI panels would request explicit bounded timestamped market context, with requests entirely outside the feed/chart hot path.
